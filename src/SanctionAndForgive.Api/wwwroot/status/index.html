List status

Which lists a screening searches, how many records each holds and how fresh it is. Lists that aren't imported are below, with the reason.

Lists searched

Each list is checked for changes daily. A list that hasn't been checked successfully within its allowed age (72 hours for the daily lists) shows Not checked in every result, never a percentage, until a check succeeds.

Update history

Every update of each list: new lists, failed downloads, and updates held for review. An update with more than 20% fewer records than the list it would replace is held: it's kept, not searched, until an administrator compares it with the publisher's site and confirms or rejects it. Meanwhile the current list keeps serving and still ages out after its allowed age.

Lists not imported

Known public lists the demo doesn't search. A screening never reports a match on these, or the absence of one.

ListWhy notLinks

Each list belongs to its publisher: check any match against the official publication. Record counts leave out vessels and aircraft, which the demo doesn't screen.
