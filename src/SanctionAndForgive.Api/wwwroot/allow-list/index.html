Allow-list

Names known to be legitimate parties that resemble a listed one: their possible matches are shown as allowed.

What an entry does

When the receiver or company entered is an allow-listed name (case, punctuation and legal forms such as “Ltd” aside; Latin and Cyrillic spellings are separate entries), its possible matches are shown as “Possible match, allowed” with the entry's reason, and don't raise the outcome. A Match is never allowed, and a name that is itself a match on a list can't be added. Every addition and removal is kept, with who and when. Only administrators can see or change the list: entries can be people's names.
