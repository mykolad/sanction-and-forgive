Lists searched

Switch a list off if it shouldn't be searched, for example while its publisher's file is known to be wrong. It stays on the status page and in Browse lists and is still updated daily, but screenings don't search it: every result says it wasn't searched, and shows your reason. Switch it on again to search it from the next screening.

Updates held for review

An update with more than 20% fewer records than the list it would replace is kept but not searched. Compare it with the publisher's site: a real change (many entries delisted) is confirmed; a broken or partial file is rejected. Until then the current list keeps serving, past its allowed age too (with a warning on every result).

A demo list check, not a legal determination. · Source code (MIT)
