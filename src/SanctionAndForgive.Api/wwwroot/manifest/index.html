Screen a manifest

Every row of a CSV file screened like a single shipment, with a results file to download.

1. Choose a file

A CSV file (comma, semicolon or tab separated; UTF-8, UTF-16 or Windows-1251/1252), up to rows. It's read here in the browser: the rows go to the screening API one by one, and nothing is stored.

2. Which columns to screen

Each row is screened with these as the receiver, the company and the address. A column left out isn't sent.
